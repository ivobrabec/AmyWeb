# Práce na amyweb

## Pushe

- Do `main` se smí pushovat přímo, pull request je volitelný a Claude ho může
  mergnout sám; push do `main` nasazuje. Kontroly běží napřed v session
  a pushuje se málokdy, hotová práce najednou. Review Claudem jen ručně
  (Actions → claude-review → Run workflow). Minuty GitHubu se počítají.
